# ISTG Studio

## 工程结构与运行

- `istg/`：信息预处理、数据封装与隐写算法。
- `backend/`：后端服务，处理请求并调用算法。
- `frontend/`：网页界面代码。
- `requirements.txt`：运行依赖清单。

在项目根目录安装依赖并运行：

```bash
python -m pip install -r requirements.txt
python run.py
```

当前在本地运行，后续可另行配置服务器部署。

## 图像隐写流程

1. 输入秘密信息和载体图片。
2. 进行信息编码与预处理。
3. 使用 CBOR 编码数据。
4. 构建 ISTG v1 数据包。
5. 按需加密数据包中的有效载荷。
6. 使用选定的隐写算法嵌入载体图片。
7. 输出隐写图片。

## 安全性分析

观察隐写前后的图片差异，展示统计结果与评价指标。

1. **自动提取分析**：按算法和参数候选尝试提取，加密数据需提供密码解密。
2. **位平面可视化**：查看隐写前后的位平面变化。
3. **隐写痕迹检测**：展示相关统计结果。
4. **性能评价**：输出指标，比较算法表现。
5. **鲁棒性测试**：观察 JPEG 压缩或噪声处理后的信息恢复情况。

## 新增功能

1. **多模态隐写**：增加音频、视频和文本载体，支持隐藏与提取秘密文字或文件。用于比较不同载体的隐写效果，以及压缩、噪声等处理对恢复结果的影响。
2. **网络隐写实验室**：支持在网络通信中传递隐藏文字，并查看流量与恢复结果。另提供双机文件传输，方便进行网络隐写与传输实验。
3. **SecretVideo 通话**：支持 2–4 人音视频通话，在视频帧中传递加密的群聊、私聊文字和小文件。也可将语音识别为文字后隐藏发送，用于演示实时通话中的信息隐藏。

## 数据封装

自定义的 **ISTG v1** 数据包分为三部分：

- **Header（固定头部）**：20 字节，记录协议标识、版本、算法和参数字段、数据长度及 CRC32 校验码。
- **Metadata（元数据）**：可变长度，使用 CBOR 编码，记录数据格式、加密相关参数等信息。
- **Payload（有效载荷）**：可变长度，保存文本、图片等信息的 CBOR 编码结果，或加密后的密文。

具体字段以代码为准，修改时应保持封装与解析一致。
